# Intake scorecard portal

`scorecard.html` is the published scorecard register. It is the system of record
for run outcomes and dispositions.

`data.json` is the nightly convenience export generated by the reporting bot
shortly after 22:00. Keys in that export are the bot's internal aliases
(`cycles_total`, `passed`, `blocked`, `pulled`). The export is informational
only and is refreshed on the next build; use the scorecard itself for final
values.
